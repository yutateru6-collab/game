# ことばパーティ — Game

スマホ向け英単語ミニゲーム集。同じ単語リストで仕分け工場、単語ボム迷路、爆弾リレー、おぼえて宝箱、3D戦車「語彙の砦」を遊べます。

## 起動

Node.js 22以降を使います。

```sh
npm ci
npm run dev
```

表示されたローカルURLをブラウザで開きます。スマホから同じLAN上のPCに接続する場合は、Viteが表示するNetwork URLを使います。
`dist/` はそのまま静的ホスティング可能な実行ファイル一式です。HTMLファイルの直接起動ではなくHTTPサーバーで開いてください。

現在の公開ページ: https://vocab-castle-gates.axlyuta.chatgpt.site
このGitHubリポジトリと公開ページの自動同期は設定していません。

## 入力

英単語と日本語訳を1行に1組、4組以上入力します。カンマ・タブ・コロン形式に対応します。

```text
reduce,減らす
affect,影響を与える
publish,出版する
compete,競う
```

単語リストはブラウザのローカルストレージに保存します。単語ごとの画像は不要です。

## おぼえて宝箱

- `dist/index.html` で単語を入力してゲームを選択。`dist/memory.html` が宝箱、`dist/tank.html` が戦車です。
- 最初の7秒で配置を覚え、英単語と日本語訳の箱を2つずつ開けます。
- 90秒で3部屋をクリア。部屋ごとに4→5→6組（単語数が少なければその数）を出題。覚える時間は90秒に含みません。
- 連続成功ボーナス、各部屋1回の3秒ヒント（50点消費）、単語セット別自己ベスト。
- 訳が同じ表記の単語を重複出題しないよう整理し、異なる訳が4組未満なら開始しません。意味の近さを自動的に判断する機能ではありません。
- 取り違えた組を終了画面で確認できます。場所の記憶ミスと語彙知識を区別できないため、語彙習得の診断とはしません。

## 爆弾リレー

- `dist/bomb.html`。登録した単語と訳の組を○×で判断し、正解ならCPUへパス。
- 不正解は1.35秒手元に残り、正しい訳を表示します。待機中やCPUの番には解答できません。
- 導火線は16〜22秒。爆発した側の相手が★を取り、先に3つ取った側の勝利。CPUの反応と正誤に乱数を使うため、判断の速さと運の勝負です。
- ○×は登録した組の照合です。別表記の同義語を理解して判定する機能ではありません。
- 明るいポップな専用画面、音のON/OFF、一時停止、復習一覧。PCでは左矢印が○、右矢印が×です。

## ことば仕分け工場

`dist/factory.html`。流れる英単語の荷物を日本語の宛先へ。荷物→宛先のタップ、またはドラッグで配達します。60秒で18個中15個以上ならクリア。取り逃がしと誤配送は合計5回で終了。宛先は1便終わるたびに変わります。

## 単語ボム迷路

`dist/maze.html`。9×9の迷路を十字キーで移動。爆弾は2.4秒後に上下左右2マスへ爆発します。青壁では止まり、木箱は1つ壊したところで止まります。爆風は自分にも当たり、爆弾同士は連鎖します。敵3体を倒して右下へ到達するとクリア。制限150秒、体力3。

単語の3択正解で爆弾を2個補充。クイズ中は時間と戦場を停止します。PCは矢印／WASD、Spaceで設置、Qで補充。オリジナルの小規模な一人用迷路ゲームです。

## 戦車の操作とルール

- 左スティック: 前後左右・斜め移動
- 右スティック: 照準。自動照準への切り替えも可能
- PC: WASD／矢印で移動、クリックで照準、Qで衝撃波、Eで自動照準、Escで一時停止
- 意味に合う単語ゲートを通ると火力が増え、多連装→貫通→雷撃へ進化
- 不正解・時間切れは火力半減、射撃停止、耐久減少
- 敵を倒すと次の道が開きます。最後のボスを倒して奥の出口へ進むと勝利

## ファイル構成

- `dist/world-engine.js`: 移動、戦闘、出題、敵、ボスのシミュレーション
- `dist/world-renderer.js`: Three.jsによる3D描画
- `dist/world-game.js`: 画面、入力、保存
- `dist/vocab.js`: 単語入力の読み取り
- `dist/vendor/`: 同梱Three.jsとライセンス
- `test-world.mjs`: v3の機能・通し検証
- `QA.md`: 検証結果と未確認事項
- `dist/engine.js`、`dist/game.js`、`test-engine.mjs`: 旧v2のコードとテスト。現在の画面はv3を使用

### ことばフィッシング DX
`fishing.html`: 8投のアーケード釣り。海の魚を選び、3種類の無料ロッド（標準・ガード・パワー）を使い分ける。単語4択の正解でヒットと必殺チャージを獲得。タイミング投げが成功すると15%先行。長押しで巻き、暴れる予告で離す。必殺技はチャージ1個を使い、糸の張りを回復して魚を引き寄せる。

3連続キャッチで次の2投がフィーバー（釣果スター2倍・必殺技強化）。最後の巨大魚は途中に追加の単語勝負があり、誤答時は意味を確認してゲージ減少から再開。ミッション報酬、釣果ランク、図鑑、サイズ・スコア記録、任意の効果音、カットインとスター演出付き。PCはスペースで巻く、Xで必殺技。異なる訳が4組以上必要。魚のイラストはオリジナル生成素材（架空種）、単語ごとの画像は不要。

参考にした公式情報：
- https://www.bandainamco.co.jp/files/58-02220E38090E987A3E3828AE382B9E38394E383AAE38383.pdf （魚に応じたロッド、電撃必殺技、大物のメダル報酬）
- https://trsp.bn-ent.net/trsp1/ （タイミングキャスト、図鑑、フィーバー）
- https://trsp.bn-ent.net/land/ （収集と次の海への進行）

原作のキャラクター・画像・コードは使用していません。報酬はゲーム内スターのみ。操作や確率を原作と同一にする再現ではなく、語彙学習とスマホ操作に合わせた独自設計です。
